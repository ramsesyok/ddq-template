# DDQ Revision

`design-doc-quarto-template`（ddq）で書いた設計書に、**見出し・表・図の単位で改訂履歴**を
付けるための VSCode 拡張です。まずその土台となる**ラベル付け**を提供します。

改訂履歴をページ単位ではなく「見出し・表・図」単位で作るには、その 3 者を一意に指す
キーが要ります。キーは Quarto のラベル（`{#sec-x}` / `label="tbl-x"` / `{#fig-x}`）を
そのまま使います。改訂で見出し文言やキャプションが変わってもラベルは変わらないので、
版をまたいだ対応付けが安定し、改訂履歴表からは `@sec-x` でそのままリンクになります。

## 使うもの

`ddq`（テンプレートのリリース一式に入っている `ddq.exe`）が要ります。文書の解釈は
すべて ddq が行い、この拡張は画面と書き戻しだけを担当します。

`ddq.exe` が `PATH` に無いときは、設定 **`ddqRevision.ddqPath`** にパスを入れてください。

## ラベル一覧

コマンドパレットで **DDQ Revision: 見出し・表・図のラベルを一覧する**（エクスプローラで
執筆フォルダを右クリックしても開けます）。

| 列 | 内容 |
|---|---|
| ☑ | 書き戻す行（ラベルの無いものだけ既定でオン） |
| ファイル・行 | 押すとその行を横に開く |
| 種別 | 見出し（深さ）／表／IPO／表(pipe)／図 |
| 名称 | 見出しの文言・表のキャプション |
| ラベル | 付いていればその値、無ければ**候補**（書き換えられる） |

候補は `ddq` が内容から決めるハッシュ（`sec-3f9a1c` など）です。**人が読みやすい名前に
書き換えてから**書き戻すのがおすすめです（`@sec-purpose` のように本文から参照するため）。

**書き戻す**を押すと、チェックした行のラベルを元の文書に足します。

- 変更は `WorkspaceEdit` 1 つにまとまるので、**Ctrl+Z ひと押しで全部戻せます**
- 未保存のバッファにも当たります（保存するかどうかは人が決めます）
- 挿入は 1 行の中だけで、行は増減しません

次のものは候補を出しません（理由を列に出します）。

- **キャプションの無い `::: {.tbl}`** … 採番されない表なので、ラベルを付けても参照できません
- **`::: {#fig-…}` で包んでいない図** … 包み直すのは文書の構造を変える操作なので、機械では行いません

## 開発

VSCode で**この `extensions/ddq-revision/` フォルダを開き**（リポジトリのルートではなく）、
F5 で拡張開発ホストを起動します。

```bash
npm install
npm run verify           # 型検査・テスト・ビルド・オフライン検査・脆弱性検査
node tests/host/run.mjs  # 実拡張ホストでの検証（インストール済みの VSCode を使う）
```

`tests/host/run.mjs` は一時フォルダに検証用の執筆フォルダを作り、専用のプロファイルで
VSCode を起動して、一覧が開くこと・書き戻しが当たること・Undo で戻ることを確かめます。
`ddq.exe` は既定で `../../cli/target/release/` のものを使います（引数でも渡せます）。

版はテンプレートの版（`../../template/VERSION`）と揃えます。`ddq release` が照合し、
違っていれば止まります。
