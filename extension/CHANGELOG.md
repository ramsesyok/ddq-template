# 変更履歴

## 2.1.0 — 未リリース

拡張を `quarto-table-support`（別リポジトリ）から design-doc-quarto-template の
`extension/` へ移し、名前を **`ddq-table-editor`（表示名 DDQ Table Editor）**に変えた版です。
版はテンプレートと揃え（0.2.0 → 2.1.0）、以後はリリース一式（`quarto-template-<版>.zip`）に
`ddq-table-editor-<版>.vsix` として同梱されます。

**挙動が変わる点**:

- コマンド ID が `quartoTable.open` → `ddqTableEditor.open`、コマンドパレットの表記が
  **DDQ Table Editor: Open Table Editor** になりました。キーバインドを付けていた場合は
  付け直してください
- 拡張 ID が `ramsesyok.ddq-table-editor` になるため、旧 `ramsesyok.quarto-table-support`
  とは別の拡張として入ります。旧版はアンインストールしてください

テーブル編集の操作感を [vscode-edit-csv](https://github.com/janisdd/vscode-edit-csv)
（Handsontable）にそろえた版です。

**挙動が変わる点**（既存の使い方に影響します）:

- 編集中の **Escape が「取り消し」**になりました（従来は確定）。確定は Enter / Tab、
  または別のセルのクリックです
- Enter で確定すると**下のセルへ移動**します（従来はその場に留まる）
- セルを選んで**文字を打つと、内容を置き換えて編集が始まります**（Excel と同じ）。
  末尾に追記したいときは Enter / F2 / ダブルクリックで入ってください
- 「行を追加」「列を追加」が**上／下・左／右**に分かれました

### セル操作

- **キーボード移動**: 矢印キー、Tab / Shift+Tab（行末で折り返し）、Home / End、
  Ctrl+Home / Ctrl+End。結合セルは飛び越える
- **範囲選択**: ドラッグ、Shift+矢印、選択の右下の ■（フィルハンドル）のドラッグ、Ctrl+A。
  結合セルに掛かる範囲は結合セル全体まで広がる。■ は選択を広げるだけで値はコピーしない
- **Delete / Backspace** で選択範囲の内容を消去（結合は崩さない）
- **Undo / Redo**: Ctrl+Z ／ Ctrl+Y（Ctrl+Shift+Z）とツールバーのボタン。セル編集・
  行列操作・結合・貼り付け・属性・列幅・揃えをすべて戻せる
- **右クリックメニュー**: 行の挿入（上／下）・削除、列の挿入（左／右）・削除、結合・解除、
  内容の消去、元に戻す／やり直す
- IME の変換途中で入力が途切れないよう、編集用の入力欄を 1 つに固定して常にフォーカスを
  持たせる作りにした（Handsontable と同じ）

## 0.2.0 — 2026-08-14

セル内に**箇条書き・番号付きリスト・段落**を書けるようにした版です。あわせて報告された
不具合（セル内改行・列幅の検査・F2）を直し、セルのコピー／貼り付けを Excel の操作感に
そろえました。

**挙動が変わる点**（既存の使い方に影響します）:

- セルを選んだ状態の Ctrl+V が、表全体の置き換えではなく**選択位置への貼り付け**になりました。
  表全体を置き換えるときは Escape で選択を解除してから貼り付けてください
- **セル内改行を含む表はグリッド表で出力**されます（従来はパイプ表＋`<br>`）
- セル本文を**マウスで選択できなくなりました**。文字を選ぶには編集モードに入ってください

### 修正

- セル内で改行できない不具合を修正（[#4](https://github.com/ramsesyok/quarto-table-support/issues/4)）。
  textarea は Alt+Enter では改行しない（改行が入るのは修飾キー無しの Enter だけ）ため、
  改行の挿入とキャレット位置の復帰を自前で行うようにした

### セル編集

- 選択セルで **F2** を押すと編集モードに入るようにした（Excel と同じくキャレットは末尾。
  [#3](https://github.com/ramsesyok/quarto-table-support/issues/3)）
- 編集中の入力欄が、中身の行数に合わせて自動で伸縮するようにした
  （改行したときに下の行が隠れないように）
- Shift+クリックの範囲選択やセルをまたぐドラッグで、ブラウザ標準のテキスト選択が
  青く塗られないようにした（範囲選択と紛らわしいため）。編集モードでは従来どおり
  文字を選択・コピーできる

### クリップボード

- **選択セルを Ctrl+C でコピー**できるようにした。形式は Excel と同じ TSV で、改行・
  タブ・`"` を含むセルは `"…"` で囲む。結合に吸収されたセルは空にする
- **Ctrl+V を選択位置への貼り付けに**した（Excel と同じ）。値が 1 つだけなら選択範囲を
  すべて埋めるので、○ / × のような値を表の中で使い回せる。はみ出す分は行・列を足す。
  結合に吸収されたセルには書き込まず、捨てた数をメッセージで知らせる
- 選択していないときの Ctrl+V は従来どおり表全体の置き換え（Excel からの取り込み）。
  タブを含むテキストだけを受け付ける点も従来どおり
- **Escape で選択を解除**できるようにした（表全体の置き換えに戻る道）

### 列幅（`widths`）の検査（[#2](https://github.com/ramsesyok/quarto-table-support/issues/2)）

- 合計が 100 を超える／負の値があるときは入力欄を赤くし、Apply を拒否する
- 空欄が 1 列だけのときは、Apply とプレビューの直前に残り幅（100 − 他列の合計）を
  自動で入れる

### 出力形式

- **セル内改行がある表はグリッド表で出力する**ようにした。パイプ表では改行が `<br>` に
  なり、箇条書き・番号付きリストをセルに置けないため。`merge-cols` を選んでいるときは、
  結合を展開した素のグリッド表にする（フィルタ側で結合される）
- グリッド表の改行 `\` を、リスト項目どうしと空行の前後には付けないようにした
  （付けると項目末尾に余分な改行が入るため）
- 文章行の直後にリストを書いたときは、書き出し時に空行を補うようにした。pandoc は
  リストで段落を中断しないため、空行が無いと `- 項目` が文字のまま出てしまう。
  エディタ上は空行なしで書ける（補った空行は読み戻しで畳むので往復で増えない）
- グリッド表のセル内の空行（段落区切り）を読み書きで保つようにした
- セル内の行頭の空白を保持するようにした（入れ子リストの階層・項目内折り返しの字下げ）。
  リスト項目の続きは `\` を付けて項目本文の桁まで下げて書き出す
- コード span（`` `…` ``）の中の `<br>` を改行に変換しないようにした
  （`<br>` を文字として説明するセルが壊れていた）
- 行末のバックスラッシュが `\\` と重なっている表を、開いて書き戻すと直すようにした。
  `\\` はエスケープされたバックスラッシュとして扱われ、改行が消えて `\` が文字として
  出てしまう。モデル側に残った行末のバックスラッシュも書き出し時に落とす
- エディタのセル表示で行頭の空白を潰さないようにした（入れ子リストの階層が見えるように）

## 0.1.0 — ベータ版（初回リリース）

`design-doc-quarto-template` の統一テーブル記法 `::: {.tbl …}` を視覚的に編集する
VSCode 拡張の最初のリリースです。ベータ版のため、実運用の前にファイルをバージョン
管理下に置くことをおすすめします。

### 機能

- `.tbl` ブロックの再編集（`.tbl` 自体をマーカーとして検出）
- 分割表の**パート単位編集**（カーソルのあるパートだけを差し替え、div 行・他パート・
  外側の `.landscape` には触れない）
- セル結合 / 解除（rowspan・colspan）
- 出力形式の自動判定 — 結合を `merge-cols` で完全再現できるかシミュレーションし、
  再現できるときだけ選択肢として提示。既定はグリッド表
- 属性の編集（`caption` / `label` / `widths` / `.unnumbered`）
- ヘッダ行数 0〜N（マルチヘッダはグリッド表で出力）
- 列ごとの揃え（左 / 中央 / 右）
- Excel からの TSV 貼り付け
- 生成 Markdown のプレビュー
- 完全オフライン動作

### 検証済みの挙動

Quarto 同梱の pandoc と `design-doc.lua` に通して確認しています。

- グリッド表の桁は**文字数ではなく表示幅**（東アジア全角=2）で数える
- グリッド表のセル内改行は**行末バックスラッシュ**（native な LineBreak になり、
  PDF でも改行され、後続行に余分な空白が入らない）
- グリッド表出力と `merge-cols` 出力は、テンプレートを通すと**同一の描画結果**になる

### 既知の制限

- 分割表のパート区切りは変更できません（読み込み・保持のみ）
- 分割表では div 属性を編集できません（変更すると全パートに影響するため）
- `.landscape` は保持のみで、UI からの付け外しはできません
- Excel の結合は取り込みません（`text/plain` の TSV のみ）
- IPO 図（`.ipo`）、旧記法 `.split-table` / `.merge-rows` は対象外です
- 表を開いたあとに**ファイルが外部で変更されると Apply を拒否**します
  （行番号がずれた状態で書き戻すと別の場所を壊すため）。表を開き直してください
